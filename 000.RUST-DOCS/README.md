# Rust
- Rust 是 静态类型（statically typed）语言，也就是说在编译时就必须知道所有变量的类型。

- 无 GC 且无需手动内存管理、性能高、工程性强、语言级安全性以及能同时得到工程派和学院派认可的语言 <sup>from “Rust语言圣经(Rust Course)”</sup>
  + 没有 GC 也无需手动内存管理,性能比肩 C++/C 还能直接调用它们的代码、安全性极高


|术语|含义|备注|
|-|-|-|
|- 零成本抽象（Zero-Cost Abstractions）是 C++ 和 Rust 等系统编程语言中的一个核心设计理念|- 如果你不使用某个高级特性，你就不需要为它付出任何代价；如果你使用了它，你付出的运行时代价也不会比手动编写底层代码更高|-|
|-|-|-|
|- Rust 的借用检查器（Borrow Checker）有一条核心规则|- 在任意给定时刻，要么只能有一个可变引用，要么只能有多个不可变引用，不能同时存在|-|
