# 使用 Drop Trait 运行清理代码
|摘要|说明|备注|参考|
|-|-|-|-|
|Drop Trait|Drop，其允许我们在值要离开作用域时自定义要执行的操作: <br/> - 当 `Box<T>` 被丢弃时会释放 box 指向的堆空间|Drop Trait 是 Rust 中的一种特殊特征，用于在值离开作用域时自动调用清理代码 <br/> - 在 Rust 中，可以指定每当值离开作用域时被执行的代码，编译器会自动插入这些代码 <br/> |[官方文档:std::opsTrait Drop ](https://doc.rust-lang.org/std/ops/trait.Drop.html)|
|-|-|-|-|
|- std::mem::drop|- std::mem::drop 函数不同于 Drop trait 中的 drop 方法。可以通过传递希望强制丢弃的值作为参数|-|-|
|-|-|-|-|
|- prelude|- prelude 是 Rust 为了方便开发者，自动导入的一组基础项，使得像 Drop 这样的 trait 总是处于可用状态，无需显式导入|-|-|
