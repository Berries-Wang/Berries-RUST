# `Box<T>` 类型智能指针 <sup>使用 `Box<T>` 指向堆上的数据</sup>
Boxes allow you to store data on the heap rather than the stack. What remains on the stack is the pointer to the heap data.  (Boxes 允许你将一个值放在堆上而不是栈上。留在栈上的则是指向堆数据的指针 -- `Box<T>`允许你将一个值分配在对上，在栈上保留一个指向指向堆上数据的指针(具有额外的元数据和功能))
- 关于堆栈: [000.RUST-DOCS/000.Rust-Ownership_所有权/000.栈_堆.md](../../000.RUST-DOCS/000.Rust-Ownership_所有权/000.栈_堆.md)


## 使用场景
|场景|说明|备注|
|-|-|-|
|- 当有一个在编译时未知大小的类型，而又想要在需要确切大小的上下文中使用这个类型值的时候|-|-|
|-|-|-|
|- 当有大量数据并希望在确保数据不被拷贝的情况下转移所有权的时候|-|-|
|-|-|-|
|- 当希望拥有一个值并只关心它的类型是否实现了特定 trait 而不是其具体类型的时候|-|- 多像OOP中的多态|


### 使用 `Box<T>` 在堆上存储数据
```rust
    let a_num = Box::new(5);
    println!("a_num = {a_num}")
```

## 思考
### `Box<T>` 大小在编译时可以计算出来？
```rust
enum List {
    Cons(i32, Box<List>),
    Nil,
}

use crate::List::{Cons, Nil};

fn main() {
    let list = Cons(1, Box::new(Cons(2, Box::new(Cons(3, Box::new(Nil))))));
}

// 因为Box<T>是一个指针(真实数据存储在堆上)，所以总是知道他需要多少空间：指针的大小并不会根据其指向的数据量而改变
```
