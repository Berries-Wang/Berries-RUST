# `Rc<T>` 引用计数智能指针
|摘要|说明|备注|参考|
|-|-|-|-|
|- 多所有权|- 为了启用多所有权需要显式地使用 Rust 类型 `Rc<T>`，其为引用计数（reference counting）的缩写|- 引用计数意味着记录一个值的引用数量来知晓这个值是否仍在被使用。如果某个值有零个引用，就代表没有任何有效引用并可以被清理。|-|
|-|-|-|-|
|-`Rc<T>` 只能用于单线程场景|-|-|-|
|-|-|-|-|
|- 使用场景1： 使用 `Rc<T>` 共享数据|-|-|-|
|-|-|-|-|
|- 何时会增加引用计数|- Rc::new : Constructs a new `Rc<T>` <br/> - Rc::clone : 只会增加引用计数，并不会进行深复制|-|-|
|-|-|-|-|
|- 何时会减少引用计数|- Drop trait 的实现当 Rc<T> 值离开作用域时自动减少引用计数|-|-|
|-|-|-|-|

## 使用场景
### 使用 `Rc<T>` 共享数据
```rust
   enum List {
       Cons(i32, Rc<List>),
       Nil,
   }
   
   use crate::List::{Cons, Nil};
   use std::rc::Rc;
   
   fn main() {
       let a = Rc::new(Cons(5, Rc::new(Cons(10, Rc::new(Nil)))));
       let b = Cons(3, Rc::clone(&a));
       let c = Cons(4, Rc::clone(&a));
       // Rc::clone 只会增加引用计数，并不会进行深复制
       // 通过使用 Rc::clone 进行引用计数，可以在视觉上区别深拷贝类的克隆和增加引用计数类的克隆
   }
```

#### 克隆 `Rc<T>` 会增加引用计数
```rust
fn main() {
    // Rc::strong_count(&a) 可以获取 Rc<T> 的当前引用计数
    let a = Rc::new(Cons(5, Rc::new(Cons(10, Rc::new(Nil)))));
    println!("count after creating a = {}", Rc::strong_count(&a));
    let b = Cons(3, Rc::clone(&a));
    println!("count after creating b = {}", Rc::strong_count(&a));
    {
        let c = Cons(4, Rc::clone(&a));
        println!("count after creating c = {}", Rc::strong_count(&a));
    }
    println!("count after c goes out of scope = {}", Rc::strong_count(&a));
}
```
