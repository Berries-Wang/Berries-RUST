# 可派生的 trait
在 Rust 中，可派生的 Trait（Derivable Traits） 是指那些编译器能够自动生成实现代码的 Trait。

不需要手动编写 impl Trait for Struct { ... } 的具体逻辑，只需在结构体或枚举上方添加 #[derive(...)] 属性，编译器就会根据你的字段类型，自动为你生成符合逻辑的实现。
